# Dock defaults and double-click

Approved by Hugo: double-click the Dock grip/free surface to open the current
application/site popup in Shortcuts. Shortcut buttons retain immediate single
click execution. Reuse native foreground/site refresh and draft-discard guards.

New manually saved shortcuts are selected for the Dock until its 64-button limit.
New application/site profiles created by the editor enable Dock. Do not change
existing disabled profiles, reselect excluded buttons on edit, reorder existing
buttons or override imported Dock configuration. At capacity save the shortcut
and explain that Dock selection needs adjustment.

Use CS_DBLCLKS on the Dock surface, cancel drag capture before opening, and avoid
saving unchanged Dock coordinates on simple clicks. No timers or schema changes.
Build Release SkipTests at the usual path; no automated tests. Document the new
local candidate in README/changelog/Library/Harness; manual acceptance before
publication. Verify double-click/context/drafts, creation/edit/removal, disabled
profiles, capacity, import and existing Dock dragging/menu behavior manually.
