# Quick Cheat 0.5.0-alpha.2

Windows x64 prerelease requested by Hugo on October 19, 2026 after confirming
website recognition in Microsoft Edge and the contextual Dock working.
This is the first public version after 0.3.0-alpha.2; it includes the 0.4 work.

## Changes since the previous public release

- Contextual native Dock: ordered shortcuts, collapse, dragging, scale, opacity,
  horizontal/vertical layout and Previous/Next pages without scrollbars.
- Dock settings with native checkboxes, selection count and explicit Apply.
- Native Edge/Chrome website profiles alongside generic browser content,
  hostname-first heading and fresh hostname confirmation before site input.
- Edge fix: allow up to 512 chrome elements instead of 128, retaining the
  400 ms deadline, focus/ambiguity rejection and renderer exclusion.
- Store v4 with pre-v4 migration backup; collection format 2 reads format 1.
- Clean-source local packaging, commit/toolchain metadata and SHA-256 hashes.
- Refreshed Dark/Light/System DEMO screenshots, including Dock and pagination.

## Package and upgrade

Extract the Windows x64 ZIP and run QuickCheat.exe. No installer or extra runtime.
Compare the ZIP with its `.zip.sha256` sidecar before extraction; the internal
SHA256SUMS.txt covers the executable, docs, licenses, screenshots and metadata.
Artifacts are unsigned. Metadata includes local toolchain paths.

Exit the previous instance normally and resolve draft prompts before replacing
the executable. Back up the entire data directory, including attachments and
ui-state.ini. Older releases cannot read v4: keep the upgraded folder and restore
shortcuts.qc.pre-v4.bak only when intentionally rolling back, losing later edits
from that restored backup. See ../local-distribution.md for recovery details.

## Evidence and limits

Hugo confirmed live Edge recognition and the Dock after the corrected build
started from build/Release/QuickCheat.exe. This confirmation is not exhaustive
coverage of Chrome, Windows versions, DPI/monitor/layout or elevated-provider cases.
Release compilation uses SkipTests. No automated tests were added or run.
Existing preview helper generated isolated fictional data and screenshots;
these are UI documentation, not evidence of real website recognition.
Normal Dock, Dock settings, popup and overflow captures were visually inspected.

The broader robustness/distribution roadmap remains ongoing: measured CPU/latency
baseline, resource budgets, supported minimum versions, recovery matrix and
installer/signing/updater decisions remain open. No community or Android support.
