# Quick Cheat 0.3.0-alpha.2

Windows x64 prerelease. Manually accepted by Hugo on October 18, 2026.

## What's new since 0.2.0-alpha.8

- Export and import a collection for one application: shortcuts, workflows, Markdown and referenced PNG images in one `.quickcheat.json` file.
- Preview incoming collections before adding or replacing content. Add skips exact duplicates; Replace confirms and changes only the matching application. Other applications and global settings stay intact.
- Bounded file/image sizes, safe attachment paths and rollback of newly created images on import failure. Existing conflicting images are never overwritten.
- A gear icon beside PIN replaces Manage shortcuts/workflows. General, Shortcuts and Workflows now open inside the same main window.
- Back returns to the library with unsaved-edit confirmation. Escape and unpinned focus loss hide to tray while retaining drafts; exiting still checks hidden edits.
- Native scrolling and keyboard navigation keep the settings controls accessible in smaller windows.

## Download and run

Download **QuickCheat-0.3.0-alpha.2-windows-x64.zip**, extract it and run **QuickCheat.exe**. No installer or separate runtime is required. The app runs in the Windows notification area. Open an application and press **Ctrl+Alt+Space**; the first-launch fallback is **Ctrl+Alt+Shift+Space** if the default is occupied. Change it with the gear → General.

**SHA256SUMS.txt** accompanies the ZIP. The package contains documentation, demo screenshots and license notices, without personal profiles or attachments.

## Updating and backups

Exit the previous process before replacing its executable. Existing v3 data needs no migration. Back up the whole `%LOCALAPPDATA%\QuickCheat` folder (or your custom `--data-dir`), including `shortcuts.qc`, `attachments` and `ui-state.ini`. Exported collections omit global settings and category expansion preferences; keep full backups for those.

## Limits

Windows x64; intended API baseline Windows 10 1809+ and Windows 11. Application matching uses the executable filename; each executable has one active profile. Collections are local files, with no community browsing or voting yet. Limits: 32 MiB collection file, 128 PNG images, 4 MiB per image and 8 MiB combined, plus existing store/text limits. See [collection format](../collection-format.md).

Workflows remain reference guides. Elevated/protected apps can block shortcut injection. Remote images and HTML execution are excluded. Native file dialogs retain Windows appearance.

## Release evidence

Hugo confirmed manual acceptance of the implemented changes. Release compilation, independent code inspection and isolated demo captures were completed; no additional automated tests were added or run. Acceptance does not imply coverage of every Windows, monitor or DPI configuration.
