# Quick Cheat 0.2.0-alpha.8

Windows x64 prerelease. Manually accepted by Hugo on October 18, 2026.

## What's new since 0.1.0-alpha.4

- Local workflows for each app: create, edit and reorder steps.
- Markdown explanations and local image attachments, rendered with native Windows controls.
- Select a workflow to read all steps with dividers, or select a step to focus on it.
- Responsive shortcut cards grouped under collapsible categories. Expansion is remembered per app.
- Larger, resizable popup with Expand/Restore, centered app title and retained external-app context.
- Pin icon to keep the popup open, with a red close icon beside it.
- Settings organized into General, Shortcuts and Workflows, including an embedded workflow editor.
- System, Light and Dark appearance throughout the UI.

## Download and run

Download **QuickCheat-0.2.0-alpha.8-windows-x64.zip**, extract it, and run **QuickCheat.exe**. No installer or separate runtime is required. The app runs in the Windows notification area. Open an application and press **Ctrl+Alt+Space**; if that shortcut was occupied on first launch, the fallback is **Ctrl+Alt+Shift+Space**. Change it in Settings → General.

**SHA256SUMS.txt** accompanies the ZIP. The package contains no personal profiles or image attachments. Screenshots in the README use isolated fictional demo data.

## Updating and backups

Exit the previous Quick Cheat process before replacing its executable. Existing data remains in `%LOCALAPPDATA%\QuickCheat` (or your custom `--data-dir`). Back up the whole folder, including `shortcuts.qc`, `attachments` and `ui-state.ini`.

Data v1/v2 is upgraded to v3 on save, with `shortcuts.qc.pre-v3.bak` preserved first. Existing v3 files require no migration. Older 0.1 releases cannot read v3. To roll back, exit Quick Cheat, preserve your current data folder, and restore the pre-v3 backup as `shortcuts.qc`.

## Current limits

Windows x64; intended API baseline Windows 10 1809+ and Windows 11. App matching uses executable filename. Elevated/protected applications can block shortcut execution. Workflows are reference guides and do not execute procedures. Markdown supports the documented basic syntax; remote images and HTML execution are excluded. The reader previews eight images at a time; select a step to access its images when a full workflow reaches that budget.
