# 0.5.0-alpha.3 — local candidate

Not accepted or published. Public release remains 0.5.0-alpha.2.

Right-click the Dock grip for Enable Dock (checked), Orientation, Scale, Opacity,
separator and Settings last. Scale presets span 50–200%; opacity 20–100%.
The current value is always available, including non-preset saved percentages.
Changes save immediately to the displayed profile; Settings opens its Dock tab.
Pending Settings edits are protected and block quick changes until resolved.
Disabling a website Dock may restore the generic browser Dock, as in Settings.
Re-enable disabled profiles through Settings. No schema or site-execution change.
